Backend: this page calls a small API (not set) that fetches Yahoo Finance server-side and computes the digital-root math. Method: for each timeframe, take the last 5 completed bars, find the highest high and lowest low, spread = high − low, digital root = repeatedly sum the spread's digits until one digit remains, result = spread ÷ digital root. If the spread reduces to 0, the root is shown as 9 by convention so the division stays defined. This is a numerological exercise, not financial advice.
